# AARX मोबाइल ऐप - यूज़र गाइड (हिंदी)

आप AARX ऐप का उपयोग करके prescription भेज सकते हैं, pharmacy से quote पा सकते हैं, और मेडिकल डिलीवरी या स्टोर से पकड़ सकते हैं।

---

## 1. ऐप कैसे खोलें

- **Android:** AARX app खोलें (या नई डेवलपमेंट बिल्ड इंस्टॉल करें)
- **iOS:** AARX app खोलें
- अगर first time खोल रहे हैं तो phone number से login करें या Google से login करें

### Login करने के तरीके:
| तरीका | कैसे करें |
|-------|----------|
| **फ़ोन नंबर (OTP)** | 10-digit number डालें → OTP receive करें → Verify करें |
| **Google Login** | Google account से login करें |
| **Emergency Access** | बिना login के emergency request भेज सकते हैं (limited) |

---

## 2. Prescription भेजना (Home Screen)

### Step 1: लोकेशन सेट करें
- Home screen खोलें
- नीचे "Select Location" पर tap करें
- GPS auto-detect होगा या map पर manually select कर सकते हैं
- Address confirm कर लेना चाहिए

### Step 2: Prescription Mode चुनें
तीन options हैं:

| Option | कब use करें |
|--------|------------|
| **Doctor Rx** | अगर आपके पास doctor का prescription है (image/scan) |
| **Pill Photo** | अगर आपने medicine की शीटी (packaging) की photo लेना चाहते हैं |
| **Type Name** | अगर आप medicine name directly type करना चाहते हैं |

### Step 3: Prescription Upload
- **Doctor Rx / Pill Photo:** Camera या gallery से photo select करें
- **Type Name:** Medicine name type करें (e., "Crocin Advance")

### Step 4: Notes (Optional)
- Jamiaa notes add कर सकते हैं (जैसे: "धोखे बनाएं", "जल्दी चाहिए" आदि)

### Step 5: Emergency बटन (Optional)
- अगर बहुत ज़रूरी है तो "Emergency Priority" toggle ON करें
- Emergency पहला broadcast free होता है (फिर ₹5 लेता है)
- Emergency से 24 घंटे के भीतर 30+ pharmacies तक पहुंच जाता है

### Step 6: Send
- नीचे "Send Price Request" या "Emergency Dispatch" बटन press करें

---

## 3. Quotes देखना (My Prescriptions)

"Prescriptions" टैब (नीचे दूसरा आइकन) पर click करें:

### क्या दिखेगा:
- **New Price Quote!** notification जब भी कोई pharmacy आपको quote भेजती है
- हर quote में: Pharmacy name, distance, total price, medicines list
- **Best Deal** badge वाला quote सबसे कम दाम वाला show करता है

### Actions:
| Action | कब | कैसे |
|--------|-----|------|
| **Accept** | जब आप किसी pharmacy को चुनते हैं | "Accept" button पर click → Delivery option चुनें |
| **Decline** | अगर कोई pharmacy दूर या महंगा है | Quote card खोलें → "Decline" |
| **Chat** | अगर आपको किसी से बात करनी है | Quote card में message icon पर click |
| **Report** | अगर कोई गलत/झूठा quote है | Report button → Category select करें |

---

## 4. Orders Track करना (My Orders)

"Orders" टैब (तीसरा आइकन) पर click करें:

### Order Status क्या होते हैं:
1. **Accepted** - आपने quote accept कर लिया
2. **Processing** - Pharmacy billing कर रहा है
3. **Ready** - लेआउट तैयार (Packed)
4. **Out for Delivery** - अगर delivery चुना है तो
5. **Completed** - Medicine मिल गई
6. **Cancelled** - कैंसिल हो गई

### Delivery Options:
- **Walk-in Pickup** - स्टोर से खुद ले जाओ
- **Home Delivery** - घर पर डिलीवरी (delivery charge lagta hai)

### Completion OTP:
- Delivery complete होने पर pharmacy ने OTP माँगा
- OTP को screen पर show होता है
- केवल pharmacy को handover के समय दें

---

## 5. Emergency Requests

### कब use करें:
- जब आपको तुरंतता से medicine chahiye
- Night time या Sunday जैसे समय पर

### क्या मिलता है:
- 30+ pharmacies तक immediate broadcast
- Real-time status: Sent → Opened → Responded → Quotes
- Pahla broadcast free hai (fir ₹5)

### कैसे track करें:
- Emergency banner home screen पर दिखेगा
- "Emergency Requests" tab पर click करके पूरा detail देख सकते हैं

---

## 6. Chat / Messages (Inbox)

"Inbox" टैब (चैट आइकन) पर click करें:

- Har order ke saath ek chat thread ban jaata hai automatically
- Store ya user dono message bhej sakte hain
- Real-time notifications milte hain

### Messages भेजना:
- Kisi bhi chat खोलें → नीचे message type करें → Send

---

## 7. Reviews / Ratings देना

Jab order complete ho jata hai:
- Rating modal khulne ki koshish karega
- 1-5 stars select karen
- Comment likh sakte hain (optional)
- Pharmacy ki rating improve hoti hai

### Pharmacy reviews देखना:
- Kisi bhi quote/store पर long press या store name पर click करके reviews देख सकते हैं

---

## 8. Complaints / Support Raise करना

### Agar koi problem hai:
1. **Order se related problem:** Orders tab → specific order → "Raise Complaint"
2. **Store se related problem:** Prescription tab → specific quote → "Report"
3. **Platform/app problem:** Platform Support tab → "Raise Ticket"

### Support ticket categories:
- **Complaint:** दूसरे store/user से related
- **Platform Support:** app, account, technical issues

## 10. Important Tips

### Prescription Quality:
- Photo clear hona chahiye (blurry mat bhejo)
- Poora prescription photo mein aana chahiye
- Lighting theek se ho (sunlight best hai)

### Emergency Use:
- केवल sach mein zaroori samay par use karo
- ₹5 charge lagta hai (first free)

### Delivery:
- Home delivery mein delivery charge lagta hai
- Walk-in pickup mein koi extra charge nahi hota
- Kya aapka area delivery-supported hai, yeh order time pe pata chalta hai

### Payment:
- Pharmacy se directly payment karo (cash ya digital)
- AARX koi payment nahi leta

### Ratings:
- Har order ke baad rating dena zaroori hai
- Rating improve karo to better stores milenge

## 11. Common Issues aur Solutions

| Problem | Solution |
|---------|----------|
| **"Location not found"** | GPS on karo, ya manually map पर click करके location fix karo |
| **"No nearby pharmacies"** | Location wrong lag raha hai to change karo, ya emergency use karo |
| **"Quote nahi aaya"** | 5-10 minutes wait karo, phir refresh karo Orders tab |
| **"Chat nahi send ho raha"** | Internet check karo, app restart karo |
| **"OTP nahi aaya"** | MSG91 SMS check karo, resubmit करें |
| **"App crash ho raha hai"** | App force close karo, update karo, ya reinstall karo |
| **"Payment failed"** | Razorpay issue ho sakta hai, store se directly pay karo |
